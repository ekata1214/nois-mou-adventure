# UNGR ARCHIVE / ムー君の冒険 — コンセプト正本

正本は本書と `docs/ASTRA-HANDOFF.md`。過去の実装・試作の目標を、作品のコンセプトや最終ゴールと取り違えない。

## 顔と役割

- **UNGR ARCHIVE が顔。ムー君の冒険はその中のフック。**
- **プレイヤーは人間。ムー君は言語化できない思考を通す媒体。**
- 入口リンクは常にホーム：<https://ekata1214.github.io/nois-mou-adventure/>
- 機能は増やしすぎない。

## 二本柱

- **NOU**：緊張・遭遇・採集。
- **殻ライフ**：内省・生活・暴力以外の遊び。
- この二本柱を混ぜて壊さない。

## 人間ゲージ

- **祝福でも警告でもある。**
- 行動するほど上がり、しないと下がる。
- 数値が高いことを、単純な善・強さ・成功と同一視しない。

## 表エンド

1. 人間100%に到達する。
2. 鏡で自分と対峙する。
3. 一度負ける。
4. 責任を持って勝つ／拒否する場合はハード再スタート。

「責任を持つ」「拒否」「ハード再スタート」の具体的な選択・演出・保存範囲は、この宣言だけから勝手に確定しない。現時点のユーザーのセーブを消去する指示ではない。

## 裏エンド

- **深く自己分析できたら成功。クリアは必須ではない。**
- 表エンドへの到達だけを、プレイヤーの成功条件にしない。
- 自己分析の深さを判定する方法や、明示的なエンディング演出の有無は、この会話と参照資料では未確認。文字数・スコアへの単純な置き換えを確定事項として扱わない。

## 戦闘と友達

- **怒・哀 = ACTION。喜・楽 = RPG。**
- 友達になった後は、同行・殻・現地など、相手によって違う。
- 全員を一律に同行させる実装を、確定した関係性として扱わない。

## 継承する世界観と質感

オーナーの直前の指定と既存正本から継承する事項：

- UAの赤と黒の質感を踏襲する。
- ムー君は人間の思考の中でしか生きられない。
- VOIDは時間と空間のある俺らの現実世界。ムー君が存在を保てない領域。
- ゼルダを参考にした試作を、この世界観やゴールより優先しない。

## 現行3D試作との区別

以下は実装上の差分であり、オーナーのコンセプト変更ではない。

- 3D野原の祠・宝箱・体力増加は、実装側が追加した仮の遊び。本作の最終ゴールではない。
- 既存の章にある人間60%は、その時点の実装の到達点。表エンドの100%・鏡・敗北・責任・拒否の代替ではない。
- 3D試作の喜の敵は選択式の遭遇へ変更済み。怒・哀はACTION。楽のRPG遭遇は未配置。
- 3D側の敵の一律同行／待機は、相手ごとに異なる友達の関係性の完成ではない。
- 3D側には、人間ゲージの増減、VOID、表・裏エンドをまだ統合できていない。
- 今後の変更は、機能追加より、この差分と正本の整合を優先する。
