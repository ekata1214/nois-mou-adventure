## 0. 一言

**人間のプレイヤーが、ムー君を通して言語化できない自分に触れ、選ぶこと自体が「人間らしさ」になる自己分析体験。**  
表のゴールはムー君を人間にすること。裏のゴールは、深く考えられたらそれで成功。  
プロダクトの顔はゲームではなく **UNGR ARCHIVE**。ゲームはその中のフック。

## 2. 世界観の核

### ムー君
- **人間の思考の中でしか生きられない**
- プレイヤーは外側の人間。ムー君は「言語化できない思考の隙間」を通す媒体
- 目的: ムー君を通して自己認識を深める

### 二空間
| 空間 | 別名 | 性質 |
|------|------|------|
| **殻** | INTROVERT / カラ | 内省・言葉・生活・回復。ゆっくり・触れる・見せびらかさない温かさ |
| **NOU** | EXTROVERT | 外のフィールド。遭遇・採集・緊張・祝福と警告 |
| **VOID** | 現実／殻の外の黒 | 宇宙っぽい。触れすぎると存在を保てない |

語感メモ: 殻 → から → 空 → VOID

### 中核リソース
- **体力（HP）**
- **人間ゲージ** — 祝福でもあり警告でもある
- **闇の思念体** — 虚無・孤独・盲目。放置／ネガ選択／殻にこもりすぎ／NOUにいすぎで増える

## 3. 人間ゲージ・エンディング

### 人間ゲージ
- **どんなアクションでも上がる**（速度はランダム）
- 理由: 「四択の中にあるものはどれも人間らしい」
- **アクションしない＝下がる**（「ゲームをしない」）
- 成長連動の希望: 人間↑ → RPG選択肢増／ACTIONは体力・攻撃↑／フィールド開放／殻要素追加

### 表エンディング
1. 人間 100%
2. **鏡ポータル** → 自分と対峙（ACTION + RPG）
3. 鏡戦は一度どんな選択でも負ける → リトライ画面
   - **はい** → 再戦は必ず勝つ → 「選択に責任を持って人間を教えてくれた」→ クリア
   - **いいえ** → 死んだムー君が起き上がり非難 → **ハードモード最初から**（アクション増で難易度↓、再戦は必ず勝てる）
4. クリア後イメージ: どうぶつの森のように **お互いの殻を行き来**

### 裏エンディング
- 「深く思考したり自己分析できたらそれで満足」— クリア必須ではない

## 4. 二本柱（混ぜて壊さない）

### A. NOU — 緊張と選択
- 移動・遭遇・採集・発見・働きかけ
- 完成像の優先: **画質よりゼルダのようなオープンワールド感**
- 四目標:
  1. 自由な移動
  2. 発見と寄り道
  3. 世界への働きかけ
  4. 採集から殻の生活へ
- 視点: ムー君背後の3D（探索試作）／既存 `game.html` は2Dトップダウン＋遭遇
- 操作土台: 歩く・走る・ジャンプ → 浮かぶ言葉・記憶へ「思考から思考へ飛び移る」
- 探索先: 住人、記憶の風景、仕掛け、素材、生き物
- 感情地形: 喜怒哀楽で景色・法則が違う
  - **怒・哀 = ACTION のみ**
  - **喜・楽 = RPG のみ**（確定）
- 遭遇演出: ポケモン寄り（遭遇まで様式は分からない）
- ACTION の将来: ガード／避ける／切る／殴る／逃げる、話しかける／撫でる／見てる／守る
- RPG 四択: 殺す／食べる／無視／友達 — **正解なし＝人間らしさ**
- 友達のその後（正典）: 同行／殻へ来る／現地で関係が続く — **相手により異なる**
- 戦闘必須にしない。歩く・触る・拾うだけでも進む

### B. 殻ライフ — 暴力以外の遊び
詳細: `docs/shell-life.md`

| Phase | 内容 | メモ |
|-------|------|------|
| Life 0 | 殻タップ移動 | 寄り道 |
| Life 1 | メモの壁 | 言葉が空間に残る |
| Life 2 | 採集＋簡易クラフト | lamp / pot / memo 寄り実装あり |
| Life 3 | 庭 | 未実装 |
| Life 4 | ペット | 未実装 |
| Life 5 | 別荘 | 未実装 |

- ゼルダから踏襲: **武器だけでなく拠点が育つ**
- 殻の問い: 内省の手段（100字以上）。曲・絵・映画あらすじ共有、AI会話は拡張候補
- 「気づいてた人いる？」は **削除** 方針
- トーン: NOU＝緊張／殻＝ゆっくり・甘くない優しさ

## 5. 現在の体験フロー（ユーザー視点）

1. ホーム（`index.html`）→ UNGR ARCHIVE ハブ
2. PLAY で `game.html`（2D本編）または `explore.html`（3D思考の野原・試作）
3. タイトル → NOU フィールド
4. 携帯は十字／パッド移動（強制横画面前提）。PCはキー＋マウス
5. 気配に触れる → RPG または ACTION
6. Tab／「殻へ戻る」→ 殻（質問・クラフト・3D部屋）
7. 左端スワイプ／ホーム → アーカイブホーム（ブラウザ戻るに依存しない）

章進行（`js/story.js`・現行）:
`殻100字 → 遭遇3 → 採集5 → クラフト1 → 使う1 → 人間60%`

※ 3D探索セーブ `nois-mou-explore-v1` と本編 `nois-mou-soul-v1` は **分離中**。統合は未完。
